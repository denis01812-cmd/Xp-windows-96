# Сторонние компоненты

## Растровый шрифт

`kernel/font8x8.hpp` содержит таблицу Basic Latin из [dhepper/font8x8](https://github.com/dhepper/font8x8/blob/master/font8x8_basic.h). Исходное указание авторства и Public Domain сохранено в файле. Авторы: Daniel Hepper; исходные данные основаны на работах Marcel Sondaar и public-domain VGA-шрифтах IBM.

Шрифт не является шрифтом из дистрибутива Windows.

## v86 — необязательный эмулятор

- Проект: [copy/v86](https://github.com/copy/v86).
- Пакет: `v86` версии `0.5.473`, зафиксирован в `package-lock.json`.
- Лицензия: BSD-2-Clause; текст находится в `node_modules/v86/LICENSE` после `npm ci` и [в исходном проекте](https://github.com/copy/v86/blob/master/LICENSE).
- Используется для браузерного просмотра и интеграционных тестов, не входит в ядро или образ `xp96.img`.

## SeaBIOS / VGA BIOS — только для v86

`tools/fetch_bios.py` получает прошивки из [каталога BIOS проекта v86](https://github.com/copy/v86/tree/315b2b0b758703ef0e6cc7b4088d6068f83f3c20/bios), ревизия `315b2b0b758703ef0e6cc7b4088d6068f83f3c20`.

- Проект исходных прошивок: [coreboot/seabios](https://github.com/coreboot/seabios).
- Лицензия: LGPL-3.0; [уведомление в каталоге v86](https://github.com/copy/v86/blob/315b2b0b758703ef0e6cc7b4088d6068f83f3c20/bios/COPYING.LESSER).
- Версия фиксирована, SHA256 каждой прошивки проверяется скриптом.
- Прошивки скачиваются в игнорируемый `.cache/bios/`, не коммитятся и не входят в `xp96.img`.

QEMU использует собственную поставку прошивок; скачивать эти файлы для запуска через `tools/run.py` или `Start-XP96.bat` не нужно. Windows-архив проекта **не содержит QEMU, его установщика или DLL**: пользователь устанавливает QEMU отдельно с официальной страницы проекта.

## Название и изображения

XP / 96 — независимый учебный проект, не связанный с Microsoft. Он не содержит файлов Windows, её логотипов, обоев, звуков или проприетарных шрифтов. Обои вычисляются в ядре, значки нарисованы собственными примитивами. Скриншот в README показывает настоящий вывод этой ОС.
